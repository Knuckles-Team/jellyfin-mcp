# Getting Help
If you are having trouble using or configuring Jellyfin, there are several ways to get help. Please ensure you read our [Community Standards](https://jellyfin.org/docs/general/community-standards) before interacting with the Jellyfin community. See the [Contact page](https://jellyfin.org/contact) for a comprehensive list of places to find community discussion and support.
